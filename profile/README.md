# WealthTech Pros

**AI-native technology for UK wealth management.**

[wealthtechpros.com](https://wealthtechpros.com)

---

WealthTech Pros is a consulting and product company helping UK wealth management
firms adopt AI safely, migrate platforms, and automate the manual data work that
sits between platforms and advisers.

## What we do

- **AI code governance** — *SGD (Specification-Governed Development):* a framework
  and GitHub App that keep AI-generated code coherent, traceable, and auditable, so
  regulated firms can adopt AI coding tools with confidence.
- **Platform migration & client data** — FCA-aware platform migration and
  dual-perspective management information, built on an aggregated data spine across
  UK investment platforms.
- **Data & adviser automation** — connectors and assistants that surface client and
  asset data to advisers without bespoke vendor integrations.

## In the open

A growing set of our work is public:

- [`sgd-public`](https://github.com/WealthTechPros/sgd-public) — public, redacted

- [`adviser-mcp`](https://github.com/WealthTechPros/adviser-mcp) — *(coming soon)*
